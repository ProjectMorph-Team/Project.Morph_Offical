# Project Morph GitHub File Index

This bundle contains the recommended root files for the GitHub repository.

## Files

1. `README.md`  
   Public project overview, authorship, status, file structure, and licence summary.

2. `LICENSE.md`  
   Active repository licence notice. This is the main GitHub licence file.

3. `SDL_FULL_TEXT.md`  
   Sustainable Development Licence v1.0 text.

4. `SDL_APPENDIX_PROJECT_MORPH.md`  
   Project Morph-specific Appendix 1 for commercial use and additional terms.

5. `GROUND_TRUTH_MANIFEST.md`  
   Authorship, provenance, prior-art boundary, and intellectual-integrity declaration.

6. `NOTICE.md`  
   Short copyright, attribution, trademark, and HCF/SDL context notice.

7. `AUTHORS.md`  
   Authorship and contribution structure.

8. `CONTRIBUTING.md`  
   Contribution acceptance and licence-preservation rules.

## Publishing

Place all files in the root directory of the GitHub repository.

The public active licence should be `LICENSE.md`.

Do not add a conflicting Creative Commons licence to the same materials unless a lawyer or the SDL provider confirms the intended dual-licensing structure.
